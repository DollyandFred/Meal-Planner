☁ Sync via JSONBin Free

JSONBin stores your planner data in the cloud. Once connected, the Sync button in the header pushes and pulls changes instantly — no files to pass around. Takes about 2 minutes to set up.

1
Create a free account at jsonbin.io — just an email and password, no card needed.
2
Get your API key: once logged in, go to API Keys in the top menu and copy your Master Key.
3
Paste it below and click Connect. The app will create your shared bin automatically.

💡 How to use it

Hit Sync (header button or above) after making any changes to push them to the cloud.

Joshua does the same on his end — Sync both pushes and pulls, so one tap keeps you both up to date.

If you both edit at the same time, last sync wins — for a two-person household this is basically never a problem.

Free tier limits: 10,000 requests/month and up to 100KB per bin — your meal planner data is tiny, you'll never get close.
